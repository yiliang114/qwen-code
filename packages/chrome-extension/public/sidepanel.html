Qwen Browser Agent standalone

Runs in Chrome. No qwen serve process required.

Model settings

By default the key is kept only for this Chrome session. Persistent extension storage is not a hardware-backed secret store. Page content needed for a task is sent to the configured ModelStudio endpoint. Actions that change a page always require confirmation.

What should I do in this tab?

I can read the page, navigate, click, fill forms, press keys, scroll, and wait for content. Page-changing actions always ask first.
